MILKGUARD LAB

Overview

MilkGuard Virtual Laboratory adalah simulator perangkat lunak untuk alat genggam deteksi dini perubahan kondisi susu: sensor optik, impedansi, dan pH diproses ESP32-S3 (disimulasikan), difusikan, lalu diklasifikasikan menjadi LAYAK, WASPADA, TERKONTAMINASI.

Status adalah keluaran algoritma berdasarkan parameter dan aturan simulasi, bukan diagnosis mikrobiologis atau jaminan keamanan pangan. Semua ambang default adalah nilai DEMONSTRASI yang dapat dikonfigurasi. Seluruh komponen berupa simulasi perangkat lunak; tidak ada pengujian perangkat fisik.

Mulai dari tab Device Simulator: nyalakan perangkat, pilih sampel, lalu Start Measurement.

Klik komponen 3D untuk melihat nama, fungsi, dan prinsip kerjanya. Seret untuk memutar, scroll untuk zoom.

Fitur & keputusan

Rule-Based

Ambang default = nilai demonstrasi, bukan ambang ilmiah. Atur sesuai kebutuhan. 0 di luar rentang = LAYAK, 1 = WASPADA, ≥2 = TERKONTAMINASI.

Decision Tree

Dataset Manager

Tiga sumber dipisah: Synthetic (buatan, untuk uji perangkat lunak), Literature (hanya data terekstrak dengan kolom source; kosong secara default), Empirical (pengukuran fisik yang Anda impor). Tidak ada data empiris atau literatur palsu.
Kolom CSV: batch_id (opsional), ph, transmittance, impedance, phase, label (LAYAK/WASPADA/TERKONTAMINASI), source (wajib untuk Literature). Train/test dipisah per batch_id jika ada.

Evaluation

Metrik dihitung pada data uji dari dataset yang dipakai melatih model (default: SINTETIS). Ini BUKAN akurasi nyata perangkat.

Documentation

Arsitektur: satu file statis (HTML+JS). State tunggal S → feats() (transmittance=(sample−dark)/(ref−dark), |Z|=√(Re²+Im²), fase=atan2(Im,Re)) → classify() (rule/tree) → upd() yang menyinkronkan OLED, LED 3D, dashboard, fusion, dan grafik. Tahap pengukuran: idle → initializing → measuring → processing → completed. Riwayat & dataset di localStorage. Three.js r128 dimuat dari cdnjs.

Menjalankan lokal: buka milkguard.html di browser (butuh internet hanya untuk memuat Three.js dari CDN; simpan file three.min.js lokal untuk mode offline penuh).

Batasan build ini: vanilla JS (bukan React/TSX), grafik canvas buatan sendiri, tanpa dataset literatur, tanpa referensi gambar (tidak terlampir), uji otomatis berupa self-test di bawah.
